# 🎮 EduQuest - Complete Gamified E-Learning Platform

## 🚀 **Live Features**

### **For Professors:**
✅ Create courses with titles, descriptions, and categories  
✅ Create interactive lessons with different content types  
✅ Build quizzes with multiple question types (MCQ, True/False, Short Answer)  
✅ Set time limits and passing scores  
✅ Track student enrollment  

### **For Students:**
✅ Browse and enroll in courses  
✅ Take real timed quizzes with countdown timer  
✅ Earn XP and virtual coins  
✅ Level up based on performance  
✅ Use power-ups during quizzes  
✅ Track progress with dashboard  
✅ Compete on global leaderboards  

### **Gamification Features:**
✅ XP system with level progression  
✅ Achievement system  
✅ Virtual currency (coins)  
✅ Daily streak tracking  
✅ Interactive quiz interface  
✅ Real-time scoring and feedback

## 🔧 *Key Features in Detail*

### *Quiz System*
- *Timed Quizzes*: Real countdown timer
- *Multiple Question Types*: MCQ, True/False, Short Answer
- *Power-ups*: Buy extra time or skip questions with coins
- *Instant Scoring*: See results immediately after submission
- *Answer Review*: Detailed breakdown of correct/incorrect answers

### *Content Creation*
- *Course Creation*: Full course management
- *Lesson Creation*: Text, video, PDF content types
- *Quiz Builder*: Interactive question builder
- *Live Preview*: Real-time form validation

### *Progress Tracking*
- *XP Bar*: Visual level progression
- *Statistics*: Track XP, coins, streak
- *Achievements*: Unlockable badges
- *Leaderboard*: Global competition

## 💾 *Data Persistence*
- Uses *localStorage* to save all data
- Works offline after first load
- No backend or database required
- All data persists between sessions

## 📱 *Responsive Design*
- Works on desktop, tablet, and mobile
- Modern UI with smooth animations
- Accessible navigation
- Fast loading (< 2 seconds)

## 🎨 *Technology Stack*
- *HTML5*: Semantic markup
- *CSS3*: Modern styling with CSS variables
- *Vanilla JavaScript*: No frameworks required
- *Font Awesome*: Icon library
- *Google Fonts*: Inter font family

## 🔒 *Security Features*
- Client-side validation
- Input sanitization
- Protected routes for professors
- Secure data handling

## 📊 *Performance*
- *100% Static*: No server-side processing
